# Bullet-Hell
### Assignment
G-Pass:

- The player can control the movement of the character with keyboard & mouse
- The enemies are spawned in the play area and start moving and attacking the player according to their behaviour and proximity
- The player automatically attacks the enemies, based on the behaviour and cooldown time of the equipped weapons
- Player can die, which restarts the game with reset attributes
- Player can acquire upgrades (eg. swords, projectiles, damage, speed)
- Upgrades can be chosen once the player levels up (eg. 2 buttons show up: "speed" or "+1 sword")
- The difficulty and/or the number of the enemies increase with the passing of time
- A UI with the current score, XP and health values is shown on the screen 
- A persistent highscore is saved and is visible in the main menu

VG-Pass:

- At least 3 enemy unit types with different behaviours
- The player can also use a gamepad to move the character
- The project comes with a tool which allows the creation of new enemy types and upgrades
- The game has a polished look & feel and runs smoothly in every condition
